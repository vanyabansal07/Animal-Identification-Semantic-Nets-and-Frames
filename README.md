\# Animal Identification Using Semantic Nets and Frames



\## About the Project

This project is a knowledge-based Artificial Intelligence application developed using Python. It identifies animals based on features selected by the user.



\## Technologies Used

\- Python

\- Tkinter

\- Pillow (PIL)



\## AI Concepts Used

\- Semantic Networks

\- Frames

\- Knowledge Representation

\- Rule-Based Reasoning



\## Animals Included

1\. Lion

2\. Tiger

3\. Elephant

4\. Shark

5\. Eagle



\## Features Used for Identification

\- Habitat

\- Food

\- Number of Legs

\- Body Covering



\## How It Works

The user selects four animal features from dropdown menus. The system compares these selections with the stored animal knowledge base. Each matching feature adds one point. If at least three out of four features match, the application displays the identified animal, its category, characteristics and image.



\## How to Run



1\. Install Python 3.

2\. Install the required library:



&#x20;  `pip install -r requirements.txt`



3\. Run the application:



&#x20;  `python main.py`



4\. Make sure all five animal PNG images are inside the `images` folder.



\## Project Note

This is an educational knowledge-based AI project. It identifies animals using user-selected characteristics and does not recognize animals directly from photographs.
